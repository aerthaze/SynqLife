# SynqLife
a college project about a digital and health wellbeing tracker.

SynqLife adalah aplikasi berbasis Python yang memantau dan menganalisis kesehatan harian kamu secara otomatis.

# 🧩 Fitur Utama

- 🌙 Sleep Tracker	Hitung durasi tidur otomatis berdasarkan waktu lokal	WorldTimeAPI
- 💧 Hydration Tracker	Rekomendasi air minum harian berdasarkan suhu & kelembapan kota pengguna	OpenWeatherMap
- 🏃 Activity Tracker	Hitung kalori terbakar berdasarkan jenis olahraga & durasi	API Ninjas Exercise API
- 🍽️ Nutrition Tracker	Hitung kalori dan kandungan gizi dari makanan	Nutritionix API
-  💬 Motivation Quotes	Tampilkan kutipan motivasi kesehatan harian	API Ninjas Quotes API

# 🛠️ Library yang Digunakan
- requests
- json
- datetime
- matplotlib
